# OSZUST — multiplayer

Lekki prototyp gry karcianej „Oszust” z pokojami i multiplayerem przez WebSocket.

## Uruchomienie
1. Zainstaluj Node.js 18+.
2. `npm install`
3. `npm start`
4. Otwórz `http://localhost:3000`.

Aby znajomi mogli wejść z internetu, serwer trzeba wdrożyć na hostingu obsługującym Node.js/WebSocket (np. Render, Railway, Fly.io, VPS) i udostępnić adres HTTPS.
